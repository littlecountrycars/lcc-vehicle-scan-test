First-time setup

  1. Pair the Veepeak once: plug it into a truck, turn the key on, then Android Settings → Bluetooth → Pair new device → OBDII. PIN is usually 1234.
  2. Tap the gear at the top and paste your monday.com API token so scans can post to Inventory Recon.
  3. Chrome menu (⋮) → Add to Home screen so this opens like an app.

Scanner

Plug the scanner in, turn the key to ON (or start the truck), then connect.

Scanner won't connect?

The Veepeak talks to one app at a time. If another scan app (Car Scanner, Torque, OBD Fusion, the Veepeak app) grabbed it first, this app can't get in, even when that app looks closed.

  1. In the other scan app's settings, turn off anything like auto-connect or connect on start. Or uninstall scan apps you don't use.
  2. Force-stop that app: Android Settings → Apps → the app → Force stop.
  3. Unplug the Veepeak for 5 seconds, plug it back in, key ON.
  4. Still stuck: turn the phone's Bluetooth off and on.

If it still fails, open the Connection log below, tap Copy log, and send it to Dylan.
